What language is this?

An n-gram is a window of n characters sliding over the text. We compare the frequencies of these windows to language profiles learned from small corpora.

Trigrams: sequences of 3 letters, often the best trade-off.

    How does it work?

    1. Each language has a sample file in data/samples/.
    2. We extract a profile from it: n-gram frequencies.
    3. Your text produces the same kind of profile.
    4. We measure cosine similarity between frequency vectors. The closest language wins.

    Try n=1 (simple letters) then n=3. Also change the text length: too short, and the ranking becomes unstable.
